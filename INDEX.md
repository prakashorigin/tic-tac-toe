## 🎮 GAME RULES

### Board Positions
```
 1 | 2 | 3
-----------
 4 | 5 | 6
-----------
 7 | 8 | 9
```

### Console Version
1. Enter a number (1-9) for your move
2. Computer automatically plays
3. First to get 3 in a row wins
4. If all 9 squares filled with no winner, it's a tie

### Web Version
1. Click any empty cell
2. Computer automatically plays
3. Win/Tie conditions same as console
4. Click "New Game" to restart
